Recording

Camera is off. Press Start camera to load the trackers.

How to record good fixtures

  1. Stand back far enough that both hands and your face stay in frame while you punch and sweep.
  2. Use good, even lighting from the front. Avoid strong backlight from windows.
  3. Pick a move chip above, press Record, wait for the 3 second countdown, perform the move 3 to 5 times with brief rests between reps, then press Stop.
  4. Record one move per file. Also record idle (hands relaxed, small natural motion) and talking (gesturing as if in conversation) as negative cases.
  5. Download each file and save it into fixtures/recorded/ in the repo. Keep the suggested kebab-case names, add a suffix for repeats, for example jab-blast-2.json.
  6. If the page cannot load models when opened as a plain file, serve the repo root locally, for example python -m http.server, then open /tools/capture.html.
